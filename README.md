# Hollow-knight-Cursor-Linux
This is a port of Newty's Hollowknight cursor pack for windows

You can find the original windoes download at:
https://www.rw-designer.com/cursor-set/hollow-knight

To install you (Linux Mint):
• Extract the .tar.gz file 
• Place the now extracted file into the .icons folder in your Home/User folder
• Go into your settings and select Themes
• Select "Advanced settings"
• Then change your cursor to "HollowKnight" !
